# Block Puzzle Editor (排面编辑器 / 视频素材生成器)

这是一个基于 **PIXI.js** 和 **GSAP** 构建的网页端高级方块游戏排面编辑器。
它的核心目标不仅仅是一个可玩的拼图游戏，而是作为一款**专业的视频素材生成工具**，用于为主播、短视频创作者快速构建特定的游戏残局（排面），并录制消除动效作为素材。

## ✨ 核心特性

- **🎨 自由绘制与智能生成**
  - 使用鼠标在网格上自由绘制目标形状，引擎会自动将你画的“洞”智能拆分为 `1x1` 到 `1x4` 的独立方块。
  - **物理合法性校验**：采用回溯算法确保所有生成的方块都拥有底部支撑，百分百按照玩家所画的排面生成，不会出现悬空和意外掉落。
- **⚙️ 高级配置与控制面板**
  - 支持调整网格尺寸、列数、视口高度、总行数等核心参数。
  - 可以拖拽滑块精细调整不同长度方块（1~4格）的生成权重概率。
  - 自定义初始关卡（LEVEL）和初始分数（SCORE）。
- **🎬 专业级视频素材录制**
  - 内置基于 `MediaRecorder` 的一键视频录制系统（WebM 格式）。
  - **支持绿幕录制 (Chroma Key)**：为解决浏览器原生透明视频录制的底层残影 Bug，专门设计了纯色绿幕录制模式，方便后期在 Premiere Pro 或 After Effects 中一键抠图叠加。
  - 录制的视频画面无缝融合了上方的分数 UI 面板与下方的游戏动态画布。
- **⚡ 流畅的交互与动效**
  - 使用 GSAP 打造平滑的方块选中、缩小以及消除退出动效。
  - 支持画面的持续向上滚动（模拟视角下移），碰到顶部边界触发 Game Over。
- **💾 存档管理系统**
  - 支持多档位的存盘与读取，数据自动持久化到本地 `localStorage`，随时随地恢复你精心设计的残局。

## 🛠️ 技术栈

- **构建工具**: [Vite](https://vitejs.dev/)
- **语言**: [TypeScript](https://www.typescriptlang.org/)
- **渲染引擎**: [PIXI.js](https://pixijs.com/) (v8)
- **动画引擎**: [GSAP](https://greensock.com/gsap/)
- **UI & 样式**: HTML5 + Vanilla CSS

## 🚀 本地开发与运行

1. **安装依赖**
   请确保你已经安装了 `Node.js` 和 `npm`。在项目根目录下运行：
   ```bash
   npm install
   ```

2. **启动开发服务器**
   ```bash
   npm run dev
   ```
   启动后，浏览器会自动打开或你可以访问终端中输出的 `localhost` 地址。

3. **构建生产版本**
   ```bash
   npm run build
   ```
   构建后的文件将输出到 `dist` 目录。

## 🎮 使用指南

1. **设置排面参数**: 页面右侧面板可以调整镜头行数、方块掉落速度、各尺寸方块的生成概率。
2. **绘制残局**: 鼠标在中间黑色网格区域点击拖拽，画出你想要的任何方块形状。
3. **生成实心块**: 绘制完成后，点击面板底部的**“生成方块”**按钮，系统会智能将其填充为真实的物理小方块。
4. **开始录制素材**: 
   - 如需视频后期抠像，请先勾选右侧的**“录制绿幕”**。
   - 点击左侧悬浮菜单的**“开始录制”**。
   - 点击**“开始游戏”**让排面向上滚动。
   - 鼠标点击画面中想消除的方块即可触发爆炸与积分上涨特效。
5. **保存视频**: 点击**“停止录制”**后，浏览器会自动下载一段 `.webm` 格式的高清无损视频素材。
